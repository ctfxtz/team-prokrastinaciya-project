## 3. Структура и состояние репозитория

### 3.1. Структура директорий
В рамках этапа была сформирована и приведена к стандарту структура каталогов проекта. Вся документация вынесена в папку `docs`, а для каждой практической работы создана индивидуальная директория с шаблоном отчёта `report.md`.

* `docs/` — регламенты команды (`raci-matrix.md`, `roles-and-responsibilities.md`, `team-contract.md`)
* `practical-works/` — папки практических работ с `practical-work-01` по `practical-work-09`
* `.gitignore` — файл исключений для Git
* `README.md` — главное описание проекта

### 3.2. История коммитов и авторы
В репозитории зафиксирована прозрачная история изменений. Все коммиты обладают осмысленными комментариями, отражающими суть изменений (настройка структуры, добавление `.gitignore`, инициализация проекта).

### 3.3. Управление изменениями (Pull Requests)
Разработка и обновление документации ведутся через механизм ветвления и пулл-реквестов:
* Выполнено успешное слияние ветки `feature/Ivan_Morozov` в ветку `main` (Пулл-реквест #1).
* В процессе интеграции и проверки находятся ветки участников команды (Пулл-реквесты #2 и #3 по обновлению отчётов).
